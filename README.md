# e-plantShopping
The e-plantShopping project is a platform that connects plant aficionados with the right plants for their needs.
Whether there is need for indoor or out door decoration, the e-plantshopping is the to go portal t satiate their green needs.
This web app project provides a landing page for customer greeting, an inventory page to peruse the available specimens, and a checkout page denoted by the cart to complete the purchase.
